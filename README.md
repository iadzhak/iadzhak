# Привет! Я Сергей Яджак

Python Backend Developer (Junior). Делаю REST API и асинхронные сервисы на Django DRF, FastAPI и FastStream, работаю с PostgreSQL, Docker, Traefik.  
В пет‑проектах закрываю полный цикл: бэкенд + фронтенд (React, TypeScript, MUI), чтобы лучше понимать интеграцию и требования к API.  
Сейчас развиваю арбитражный сканер: агрегация биржевых данных, фильтры по марже, подписка и уведомления.  
Ищу позицию Junior Backend, чтобы расти в продуктовой команде и участвовать в проектировании архитектуры.

- Микросервисная архитектура: проектирование сервисов, контракты API, версионирование.
- Асинхронные пайплайны и стримы: FastStream, паттерны обработки событий, доставка и гарантии.
- Обратный прокси и маршрутизация через Traefik: entrypoints, middleware, динамические правила.
